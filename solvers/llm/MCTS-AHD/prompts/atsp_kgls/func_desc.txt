The `arc_badness` function scores the arcs of the tour the search is currently holding, and the knowledge-guided local search then penalises the arc with the highest value of badness[i] / (1 + penalty_count[u][v]), where u = tour[i] and v = tour[(i + 1) % n]. Larger means "abandon this arc sooner". Inputs: `distance_matrix` is the directed (n, n) cost matrix of an Asymmetric TSP instance, where distance_matrix[i][j] is the cost of travelling FROM city i TO city j and is generally NOT equal to distance_matrix[j][i]; `tour` is an int array of length n giving the current visiting order, so its arcs are tour[i] -> tour[(i+1) % n]; `penalty_count` is the (n, n) array of how many times each directed arc has already been penalised in this run; `iteration` is the outer iteration index, starting at 0. The function must return a float array of shape (n,) — one score per tour arc, in tour order — and every value must be finite. Only relative magnitudes matter. Because the current tour and the penalty history are visible, the rule can change what it considers bad as the search progresses, which a static guide cannot. Use vectorized NumPy (fancy indexing such as distance_matrix[tour, np.roll(tour, -1)], broadcasting, np.min(axis=...)) and no Python loops: the function is called once per iteration on instances of up to 443 cities.
