The select_next_node function takes as input the current node, the destination_node, a set of unvisited nodes, and a directed distance matrix, and returns the next node to visit. distance_matrix[i][j] is the cost of travelling FROM node i TO node j and is generally NOT equal to distance_matrix[j][i], so the cost of reaching a node and the cost of leaving it are different quantities. The returned node must be an element of unvisited_nodes. The function is called once per construction step until the tour is complete, so it must stay cheap: instances go up to 443 nodes.
