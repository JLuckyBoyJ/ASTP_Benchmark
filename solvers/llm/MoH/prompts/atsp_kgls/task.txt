Task: Given the cost matrix of an Asymmetric Travelling Salesman Problem (ATSP), the tour the local search is currently sitting on, and the penalties applied so far, design a badness measure that decides which arc of the current tour the search should abandon next, with the final goal of finding a closed tour of minimum total cost. The matrix is directed, and each directed arc carries its own penalty counter. You should create a heuristic that scores every arc of the current tour.
