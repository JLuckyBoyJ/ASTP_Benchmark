Task: Given the cost matrix of an Asymmetric Travelling Salesman Problem (ATSP), a partially built tour, and the set of cities not yet visited, design a rule that selects the next city to visit, with the final goal of building a closed tour of minimum total cost. The matrix is directed: the cost of going from the current city to a candidate is not the cost of coming back, so the rule has to weigh the arc it commits to now against the arcs it will still be able to use later. You should create a heuristic that selects the next node at each step.
