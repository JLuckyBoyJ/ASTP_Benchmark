'current_node' and 'destination_node' are integer city IDs; 'destination_node' is the city the tour started from and must return to. 'unvisited_nodes' is a Python SET of integer city IDs that have not been visited yet — it is not an array, so index it with `for node in unvisited_nodes`, never with `unvisited_nodes[k]`. 'distance_matrix' is the (n, n) Numpy cost matrix, where entry [i, j] is the cost of travelling FROM i TO j; it is asymmetric, so distance_matrix[i, j] != distance_matrix[j, i] in general, and the diagonal is 0. 'next_node' must be one integer ID drawn from 'unvisited_nodes'; returning anything else fails the evaluation immediately.
Do not change the function name. Remember to use # at the beginning of each comment inside and outside the codeblock. Never modify 'unvisited_nodes' or 'distance_matrix' in place. Write Python code that is deterministic and reproducible: ties must be broken the same way on every run. NEVER include any random or non-deterministic snippets in the code. For example: import random, np.random, random.randint, etc. We will not take solutions with random into consideration. This function is called n-1 times per instance, so a rule that scans the whole matrix on every call costs O(n^3) overall; prefer vectorised numpy over nested Python loops.
