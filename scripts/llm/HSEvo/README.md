# scripts/llm/HSEvo/

Executable shell scripts and runbook for HSEvo on ATSP tasks.

## Contents

- `smoke.sh`: Fast 0-LLM check of local ATSP evaluation scripts.
- `run_all.sh`: Runs HSEvo evolution across `atsp_constructive`, `atsp_gls`, `atsp_aco`.
- `baselines.sh`: Benchmarks baseline seed functions on TSPLIB test set.
- `calibrate.sh`: 2-eval test run for fast calibration.
- `RUNBOOK.md`: Complete list of execution commands.
